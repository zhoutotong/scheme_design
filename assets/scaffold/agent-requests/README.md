# Agent 修改请求

本目录供设计正文页内「向 Agent 提要求」写入修改说明。

| 文件 | 说明 |
|------|------|
| `pending.md` | 最新待处理要求（每次提交覆盖） |
| `archive/` | 历史提交备份 |

## 用法

1. 启动：`python3 scripts/serve_docs.py`，打开对应正文页
2. 「向 Agent 提要求」→ 点选模块 / 标题 / 框图（或先选中文字再「用选区」）
3. 右侧边栏填写说明 →「加入清单」；可继续选用多个目标
4. 「一并提交」写入 `pending.md`，或「复制给 Agent」；对话中亦可 `@agent-requests/pending.md`

网页无法直接注入当前 Agent 会话；以清单文件 + 粘贴/引用衔接。
